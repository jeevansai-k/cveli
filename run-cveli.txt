1. Open a terminal in `/home/baymax/cve-cli`.
2. Create a virtual environment:
   `python3 -m venv .venv`
3. Activate it:
   `source .venv/bin/activate`
4. Install the project:
  Use one of these:

  # inside your venv, with network
  pip install -U pip setuptools wheel
  pip install -e ".[dev]

  or, if setuptools is already installed in that venv:

  pip install -e ".[dev]" --no-build-isolation
   `pip install -e ".[dev]"`
5. Check the CLI:
   `cveli --help`
6. Show the version:
   `cveli version`
7. Search local data:
   `cveli search OpenSSL`
8. Sync fresh data from NVD and CISA KEV:
   `cveli sync --query OpenSSL --limit 20`
9. Check stats:
   `cveli stats`
10. Launch the TUI:
    `cveli tui`
11. Run tests:
    `.venv/bin/pytest -q`
